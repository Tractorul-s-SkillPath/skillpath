# components/

Shared, presentational, **no data fetching** (ARCHITECTURE §3 folder rule).

- `ui/` — shadcn/ui primitives. Generated by the CLI, edited only when we
  genuinely need to. Do not hand-write files in here.
- Everything else — our own shared pieces.

Route-specific components live next to their route (e.g.
`app/(student)/assessments/[id]/question-card.tsx`) so ownership stays with the
person who owns that slice and merge conflicts stay rare (§9).

A component in here that imports from `lib/repositories` or `lib/supabase` is in
the wrong folder.
